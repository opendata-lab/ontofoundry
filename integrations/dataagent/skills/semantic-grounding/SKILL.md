# 问题语义锚定路由

先把问题映射到已发布本体再查数：口径、对象和实体都以本体为准，不凭字面猜表或补口径。

1. 读[取定义](references/steps/ground.md)：按顺序检索定义、解析实体名称，掌握查询语义。
2. 读[结构化理解](references/steps/answer.md)：输出结构化理解；有缺项或歧义先追问，齐全才查询并回答。
