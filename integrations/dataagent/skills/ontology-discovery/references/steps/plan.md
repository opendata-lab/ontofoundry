# 计划：只定范围

只定概念与动作，细节留到抽取。

1. 读材料保留行号；JSON／CSV 先 `--outline` 再 `--pointer`，不分页；完整本体材料是否照搬自行判断。表看初始化清单（截断才 `--search-tables`），候选 t# 写 plan.md，排除废弃、备份、测试表；看列一次 `--describe-tables`。
2. 区分概念与实例：概念是一类东西，具名的具体事物（产品/人/单据）是实例（如《晨读》属“期刊”）。单值归属性，跨行归指标；材料明写操作、对象与结果的列入动作（状态列/单次记录不算）。表看行粒度（实体/事件/明细/时点/汇总），含日期见[表类型](../table-kinds.md)；汇总只作指标源。表行不抽实例；CSV 成批记录第 4 步问。
3. 不定关系、属性，不读原则、Schema，不运行 show_example.py，本体为空不运行 show_element.py；第 3 轮前定稿。
4. 需用户取舍（粒度、口径等）用 AskUserQuestion 提问，每题 2–4 项并标推荐（成批记录推荐不抽或只抽点名）；答后再写计划。
5. 计划模式调 ExitPlanMode 提交：首行 `# 标题`，写场景（全量/增量）和概念/动作表（名称/英文标识、说明、依据：行号或表、例子；增量标新增/已有）。获批前不抽取。
6. 获批准后（非计划模式直接）把场景写 plan.md 首行、依据记 notes.md，再读[抽取](extract.md)。
