# 导入待补全

工作包的 import_report 给出条数、缺表数和报告路径。导入项已在本轮草稿，不重读材料原文；核对某处时按报告的 JSON Pointer 用 read_input.py --pointer 定点读。

计划逐项写出下列四项，抽取时逐项做完，最终回答逐项说明结果，不能只做其中一部分：

1. **快照列**：逐个数据集看登记表结构。每日全量的表（主键含日期列）在该数据集写 snapshot_date_column，依据写进 reason；不是快照表的说明理由。
2. **物理连接**：报告里每条未证明的连接，按两端登记主键判断。成立就写关系对接；不成立的列为未交付并写原因，不能跳过。
3. **中文显示名**：导入只有英文标识，为对象、属性、关系、指标写中文 display_name，必要时补描述。
4. **其他待补全**：缺的映射等。导入时未转换的规则（报告里的 error），能改写成核心支持的写法才写，否则列为未交付，不要原样再提交。

修改导入项用 show_element.py 取真实 UUID，保留原证据（材料 SHA、行号、引文）；已有元素不重复新增。缺表时请用户把表加入会话后再补。报告提示导入失败时按普通材料读；提示已有待审时请用户先处理提案。
