# 接口整理第一步实施计划

日期：2026-11-16。依据 `docs/design/2026-11-16-agent-platform-interface.md` 第 3 节和第 7 节第一步，以及本次交接任务。

## 范围

- 统一工作空间接口前缀，迁移 MCP 网关、空间目录、运行提交地址和所有服务端生成的地址。
- 提交端点按会话寻址，运行身份继续由凭据核定，保持现有回执、重试、状态检查和修正轮次。
- 调整发布预览与事实修订路径，删除交接任务列出的无生产调用路由。
- 按资源归属搬移处理器，将会话锁、三方合并和事务机械下沉到服务层，保留原有错误响应。
- 更新后端测试、插件配置和交付文档。前端由并行任务负责，本任务提供完整路径对照表。

## 顺序

1. 记录原有路由，完成路径、模块和服务层迁移。
2. 更新运行输入、目录地址、导出磁盘缓存读取及部署说明。
3. 统一更新受影响测试，补充会话凭据范围、旧路由删除和旧导出缓存地址的回归检查。
4. 全部编辑后运行交接指定的 pytest 和 Ruff 命令，核对路由及差异，输出交接结果。

## 验收

- 新路径保留原有权限、请求与响应内容、事务和运行检查顺序。
- 已删除路径和旧前缀没有转发入口。
- 第 2 步的工作空间级元素保存与会话 PUT 行为保持现状。
- 测试结果、跳过项、外部部署待办和任何偏离写入交接结果。
