# 元素引用跳转与来源配置计划

1. 来源配置直接展示，去掉绑定方式说明及底部解除按钮，来源行承接移除操作。
2. 引用入口恢复为名称文字链接，不加箭头；关系标题直接打开完整定义。
3. （2026-10-20）新增 `elements/:kind/:id` 详情页路由，复用弹窗的加载、编辑、保存和页签内容；页签、会话、预览写入查询参数。
4. 弹窗改为页面本地状态，只由本体视图的语义画布和资源树、构建结果的本体草稿和语义图谱、发布页变更预览打开；去掉复制链接和 `?inspect=` 地址同步，标题增加“打开详情”。
5. 目录、数据管理、全局搜索、实例页和语义视图列表模式改为打开详情页；旧 `?inspect=` 与旧对象/关系地址转到详情页。
6. 工作区页签：详情页按类型显示图标，新建保存后提升为同一页签，页签内可关闭自身；未保存保护改为关闭页签和离开空间时确认。
7. 使用虚构演示数据人工查看跳转及返回，不运行测试、构建或 lint，不提交或推送。
