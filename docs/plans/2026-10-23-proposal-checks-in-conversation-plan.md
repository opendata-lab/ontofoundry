# 提案检查前移到对话实施计划

日期：2026-10-23。对应设计：[提案检查前移到对话、入库不整批拒收](../design/2026-10-23-proposal-checks-in-conversation.md)。

## 范围与顺序

仅在 `feat/proposal-checks` 工作树实现 CK-02、CK-03、CK-01；CK-04 不改。不可接受状态属于已确认的运行与提案审核协议，不进入本体模型；原因必须持久化，避免读接口丢失入库诊断。

1. CK-02：保留格式、引用和固定上下文契约校验；提案组按依赖拓扑序逐组试应用与整图校验，失败组及依赖组记录不可接受原因，独立组正常入库。同步存储、迁移、读接口、接受保护与前端状态显示。
2. CK-03：运行失败或含不可接受项时在对话显示平台消息、原因摘要和受影响数量；重试只提交“重试”，强制建模模式；移除右侧运行失败提示。
3. CK-01：新增与 MCP 共用运行授权的只读检查接口，复用解析与逐组规则；同步 JSON Schema、Pydantic 和前端类型。合并脚本本地通过后使用工作包 MCP 地址与凭据调用平台，原样输出可操作诊断；不可达明确提示跳过。
