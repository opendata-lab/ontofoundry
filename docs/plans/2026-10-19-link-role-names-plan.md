# 关系角色名称实施计划

依据：[设计及已确认决定](../design/2026-10-19-link-role-names.md)。

1. 核心：新增可选两端角色名、哈希空值兼容，同步生成 JSON Schema 与前端类型。
2. 交换：二元及重化实体角色导入、目标原生输出与源扩展、消除对应 RT-21 损失。
3. 界面：概览编辑、双向标题、关联实例和列表优先角色名，保留旧名称回退及自关联两个方向。
4. 文档：修订主设计、概念、UI 共识、DataAgent 技能参考；核对可用运行配置。
5. 人工查看页面，检查生成差异；按用户要求不运行测试、构建或 lint。不提交、不推送。

## 实施结果

- 已新增两端角色字段，生成核心及提案 JSON Schema、前端类型，接入现有保存/合并/查询路径。空角色名从语义规范化中省略，兼容旧哈希。
- 已同步 Ossie 导入导出及扩展，实体角色不再按 RT-21 报独立名称损失；概念与主设计已修订。
- 已接入方向标题、数量行、实例分组与表头、关系列表、派生关联选择、目录和 MCP 搜索；自关联列表按两个方向显示。
- 当前预览后端已重启至新增字段版本；已通过局域网地址人工查看角色编辑和双向描述，示例输入仅在临时页面展示，未保存或发布业务数据。
- 技能参考已同步到本机配置的 SKILLS_ROOT_DIR；未发现 DataAgent 后端运行进程，因此未启动或重启该外部服务，待其启动时加载新技能。已有 Agent 提示词未修改。
- 未运行测试、构建、lint 或自动化视觉测试，未提交或推送。
- 后续用户已确认恢复完整 verbalizes，按独立的 link-verbalizations 设计及计划继续实施。
