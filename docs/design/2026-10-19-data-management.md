# 数据管理与文档使用情况

状态：已确认，实施中；暂不运行测试。

## 已确认决定

| 主题 | 决定 |
|---|---|
| 导航 | 原数据映射改为数据管理，保留原路由兼容已有链接 |
| 页签 | 数据集 / 文档；移除本体映射汇总页签，实际对象和关系映射仍在元素详情配置 |
| 文档管理 | 汇总工作空间已上传材料，支持上传、搜索、按使用情况筛选、下载和删除未使用材料 |
| 数量 | 实体定义、关系定义、实体实例、关系实例分别显示；属性、规则、指标数量作为补充详情 |
| 统计范围 | 全部已发布版本、会话草稿和提案中直接引用该材料的元素，按元素种类和 id 去重；历史提案也计入，不把次数当成元素数 |
| 未使用 | 未被会话、运行清单、提案、导入报告或历史版本引用；实体/关系为零不等于未使用 |
| 删除 | 复用既有管理员删除权限及后端引用检查，列表显示阻止原因，用户在确认框确认后删除；本次开发不实际删除材料 |
| 模型 | 引用数量和使用状态从现有证据、会话和版本推导，不增加本体模型字段或数据库列 |

数量是来源管理的派生统计，不属于本体语义，来自用户指定的文档管理需求。只统计材料显式证据，不推断“选过材料就生成了所有元素”。

## 操作反馈补充

用户确认操作错误使用浮动消息，避免正文出现挤占布局的错误条。构建页不再在标题区显示 DataAgent 配置入口；发送不可用时通过按钮 Tooltip 提示原因，空间设置沿用侧栏入口。数据管理操作同样使用 Ant Design message 反馈。

## 演示数据

用户要求准备有数据的页面。独立预览数据库新增“虚构演示 · 星海业务全景”工作空间，复用既有销售、员工关系、文档事实和快照示例；包含真实可读取的虚构物理表、7 份材料、已发布版本、3 个建模会话和3项待审提案。演示提案明确标记为虚构，没有伪造 Agent 对话或远程运行记录，AI 对话仍需配置 DataAgent。
