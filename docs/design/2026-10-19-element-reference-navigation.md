# 元素引用跳转与来源配置简化

状态：已确认，实施中；暂不运行测试。2026-10-20 改为独立详情页，弹窗只保留给语义图。

## 已确认决定

| 主题 | 决定 |
|---|---|
| 引用入口 | 对象、关系、数据集等详情入口使用名称文字链接，不加箭头或按钮边框；关系完整定义入口放在关系详情标题上，不放详情底部 |
| 详情页（2026-10-20） | 每个本体元素有独立详情页 `/workspaces/<空间>/elements/<类型>/<标识>`，在新的工作区页签打开，页签标题为元素名；同一元素（同一会话或预览）再次打开时切到已有页签。页签选择、会话和预览写在地址里，刷新后停留在原页签 |
| 弹窗范围（2026-10-20） | 原则：在页面上就地查看时打开弹窗，已在弹窗内时进入详情页。本体视图的语义图（画布和资源树）、本体构建结果的本体草稿列表和语义图谱、发布页的变更预览打开详情弹窗（构建结果按当前会话草稿，发布预览按合并预览）；提案详情本身是弹窗，不含元素入口。目录、数据管理、全局搜索、实例页及本体视图的指标/数据集列表打开详情页 |
| 弹窗内导航（2026-10-20） | 弹窗标题右侧提供“打开详情”，进入当前元素的详情页；弹窗内的引用和关系图节点同样进入对应详情页，进入前关闭弹窗并丢弃未保存编辑。弹窗不提供复制链接，状态不写入地址，刷新后不再恢复弹窗 |
| 详情页内导航 | 详情页内的引用和关系图节点打开对应元素的详情页（新页签），当前页的编辑内容保留；同一元素的引用只切换页签 |
| 新建 | 目录中的“新建”打开新建详情页，保存后同一页签切到新元素地址；新建时取消直接关闭该页签 |
| 旧链接 | 旧的 `?inspect=` 链接与 `objects/<id>`、`relations/<id>` 旧地址转到对应详情页，并替换原页签 |
| 编辑保护 | 弹窗或详情页有未保存编辑时，关闭页签或离开工作空间需要确认；切换工作区页签不丢失编辑 |
| 来源展示 | 直接展示数据来源，删除管理/收起切换；不展示“实例来源：独立绑定”或重复的绑定方式 |
| 来源移除 | 移除来源的操作放在来源行右侧，不再在配置底部放统一解除按钮。主表行承接原整体解除行为，确认说明会同时清除附表及属性绑定；附表仍只移除自身及相关属性绑定 |
| 唯一键 | 键列统一称“唯一键”；编辑态数据集和唯一键均有固定可见字段名。支持一列或多列，说明逻辑唯一性和快照时点，不要求数据库已声明物理主键 |
| 属性详情 | 移除顶部重复的属性名/技术名标题，保留基本信息中的名称与技术名；标识、唯一、必填在查看态使用 Tag，标识解释为业务实例身份，可由多个属性共同组成 |

本次只调整界面、地址及工作区页签的导航方式，不新增本体语义或存储字段，不改变数据映射模型。
