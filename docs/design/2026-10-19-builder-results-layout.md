# 构建结果分类、会话工具与发布入口

状态：已确认并实施；暂不运行测试。

## 已确认决定

| 主题 | 决定 |
|---|---|
| 草稿分类 | 参照用户原图，使用图标＋名称＋数量网格按钮，蓝色边框表示选中，搜索与发布在下一行 |
| 分类范围 | 保留已有实体、关系、属性、规则、指标、数据集、映射、文档事实、文档关系，不新增旧版本特有概念 |
| 会话入口 | 历史、新建移到中间对话区右上角，均使用带 Tooltip 的图标按钮 |
| 历史选择 | 历史图标打开 Modal，复用已有会话搜索、排序、状态、更新时间及选择行为；发布页的选择器保留现有用法 |
| 发布位置 | 仅在本体草稿的搜索框右侧提供发布本体，不再位于整个页面顶部 |
| 发布条件 | 既有 latest_batch_id 非空、base_diff 有实际修改，且非运行/上传/忙碌状态；仅生成待审提案不能发布空草稿 |
| 发布行为 | 按既有会话进入发布页预检，不直接调用发布接口，不新增持久化状态 |
| 视觉与验证 | Ant Design 控件、现有字号/间距/语义色，网格最小宽度集中在 tokens.css；仅人工查看，暂不跑测试、构建或 lint |

后续位置修订（当前生效）：发布本体放在本体草稿搜索框右边，同一行；搜索弹性占据剩余宽度，发布按钮保持完整，不放在上方页签栏。启用条件及发布预检流程不变。

历史弹窗内容宽度修订：Modal 模式中的搜索及表格占满正文宽度，不沿用 Popover 的固定内容宽度；原下拉模式保持原宽度。
