# 本体对象统一目录与操作入口

状态：已确认并实施，按用户安排暂未运行测试。

## 已确认决定

| 主题 | 决定 |
|---|---|
| 主导航 | 保留本体视图、本体对象、本体构建；移除本体关系、本体发布侧栏项 |
| 对象目录 | 本体对象页面内以实体 / 关系 / 指标三个 Tab 管理，分别保留列表、搜索、新建及详情入口 |
| 统一操作 | 本体对象右上角集中导入、导出、发布；各 Tab 的新建操作位于列表工具栏 |
| 入口修订 | 此决定替代此前将导入放在本体视图页的安排；视图专注浏览，不重复导入操作 |
| 导入 | 沿用原预览、确认、生成提案流程，确认后进入对应构建会话 |
| 导出 | 复用已有已发布版本导出弹窗及转换报告，不新增导出草稿能力 |
| 发布 | 沿用已有发布页和预检流程，仅移除侧栏菜单，不删除历史、服务和发布能力 |
| 兼容 | 旧 relations 地址转入对象目录的关系 Tab；关系详情、会话参数及旧发布地址继续可用 |
| 模型 | 不改核心模型、接口契约和权限；指标复用既有定义、数据集归属及详情弹窗 |
| 验证 | 仅人工查看，按用户安排不运行测试、构建或 lint |

## 后续确认及当前布局

用户进一步明确删除“全局”：本体视图直接进入语义视图，不保留模式切换或分层总览。此前结构化/非结构化数据来源并列的全局图示方案随之取消，不再增加浏览层级。语义视图去掉重复选中项浮动条，资源管理器收起后释放全部占位，图谱左上角保留展开入口，列表模式入口放工具栏。

目录 Tab 使用 catalogTab 查询参数记录，切换保留 session 及详情参数。指标复用现有定义、来源数据集和详情编辑，不新建独立模型。全局搜索的关系、指标结果进入对应目录 Tab；发布旧页继续承载预检、历史、服务，导出仅支持已有已发布版本。

人工查看结果：当前预览可直接进入语义图，收起后画布无侧栏占位；统一目录三类计数与列表可切换，旧 relations 地址进入关系页签。未执行测试、构建或 lint。

## 目录表格列（2026-10-20 确认）

目录改为一行一条记录的扁平表格，不再在名称下叠放技术名、继承和描述。名称为链接，在新的工作区页签打开元素详情页；technical_name 在界面统一称“英文标识”（UI-025）。

| 页签 | 列 |
|---|---|
| 实体 | 名称、英文标识、继承自、标签、属性、关系、数据映射、文档实例、描述 |
| 关系 | 名称（即英文标识，关系没有中文名称）、关系含义、基数、标签、描述 |
| 指标 | 名称、英文标识、类型、数据集、描述 |

- 关系含义取第一条正向含义并代入两端名称，例如“合同签约方当事人”；未填写时显示“来源 → 目标”。只读推导，不新增字段。
- 标签使用 Tag，可多个；继承关系单独一列，不混入标签。
- 描述单行截断，悬停显示全文；搜索仍匹配描述。
- 数据映射显示状态而非数量，口径与详情页页头一致：已映射、已映射 3/5 个属性、未映射属性、未绑定数据集、虚拟父对象（实例来自子对象）；用 StatusMark，从现有定义推导。
- 数量如实显示 0，无值或不适用显示 `—`（UI-003）。
- 表格按内容自动分配列宽，数量列紧凑，英文标识不换行。
