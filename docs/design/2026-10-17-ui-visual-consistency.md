# 界面视觉一致性：还原原有视觉语言并固化为约束

状态：已确认（2026-10-17 选定方向 A）

共识更新：2026-10-19 将跨产品共识集中到 [企业 ToB 产品界面设计共识](2026-10-19-tob-ui-design-principles.md)，本文维护当前项目的视觉实现规则。

## 1. 背景

core-1 P0 起前端改用 Ant Design 5 + Tailwind CSS v4。功能迁移完成后，整体观感不如原来：

- 页面没有统一的容器层级，页签、筛选、搜索和表格分散铺在背景上；
- 左边缘不对齐，同一页面里标题、页签、表格首列各在一条线上；
- 字号 13/14/15/22px 混用，按钮是胶囊圆角而输入框是小圆角；
- 状态用粗进度条加撑满整列的带框标签，视觉重心落在状态上；
- 行高变大，信息密度下降。

原因不在组件库。组件库只提供控件，不规定“怎么组装”：容器层级、对齐线、字号和间距档位、状态显示方式、表格密度。这层规则没有写下来，各次生成各自决定；同时存在 `tokens.css`、Ant Design 主题覆盖、Tailwind 任意值和 `!` 强制覆盖三套样式来源；验收只验证功能，不比对视觉。

2026-10-17 在数据映射页并排试验了两个方向：A 在 Ant Design 上还原原有视觉语言，B 采用 Ant Design Pro 标准中后台风格。A 更紧凑、对齐更干净，最接近原来的专业感，选定 A。

## 3. 视觉规则

### 3.1 颜色

| 用途 | 变量 | 说明 |
|---|---|---|
| 画布 | `--color-canvas` | 页面底层背景 |
| 面板 | `--color-surface` | 面板、输入框、表格主体 |
| 表头/悬停 | `--color-surface-raised` | 表头、行悬停、面板底注 |
| 柔和填充 | `--color-surface-soft` | 分段筛选轨道、默认标签底 |
| 分割线 | `--color-rule-soft` / `--color-rule` / `--color-rule-strong` | 弱分割、标准边框、悬停强调 |
| 文字 | `--color-ink` / `--color-ink-2` / `--color-muted` / `--color-subtle` | 标题、正文、辅助、占位 |
| 品牌 | `--color-accent` / `--color-accent-soft` | 主按钮、激活页签、链接 |
| 语义 | `--color-success` / `--color-warning` / `--color-danger`（含 `-soft`） | 状态文字与图标；成功色用深绿 |

### 3.2 尺寸档位

| 项 | 档位 |
|---|---|
| 字号 | 12px（表头、技术名、状态、标签、辅助说明）、14px（正文、控件、页签、小节标题）、16px（页面与弹窗标题），不允许第 4 档 |
| 行高 | 1.35（小字与标题）、1.45（正文与表格） |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24px |
| 圆角 | 4px（小号控件、标签）、6px（按钮、输入框、下拉框）、8px（面板、卡片、弹窗）；不使用胶囊圆角 |
| 控件高度 | 28px（面板工具栏内）、32px（标准）、36px（特殊强调） |
| 表格 | 单元格 10px × 16px，紧凑表格 8px × 12px；表头 12px、辅助色、无竖分割线 |

### 3.3 容器与对齐

- 页面最多两层容器：画布 → 白色面板。面板内用分割线分区，不再套卡片。
- 页面级对齐线：页面左右内边距 24px，页头标题与面板外框左边缘对齐，页头动作按钮与面板右边缘对齐。
- 面板内对齐线：16px，面板工具栏、表格首列、底部说明左边缘对齐。
- 页签、状态筛选、搜索放在面板顶部同一行。

### 3.4 状态显示

- 状态统一用 `StatusMark`：语义色小图标 + 12px 文字，不加背景框和边框；不用带颜色的 `Tag` 表示状态。
- 覆盖率：12px 比例文字 + 56px 宽、4px 高的细进度条，下接 `StatusMark`。

U1 框架页签采用 Ant Design editable-card Tabs，页面仍通过 items.children 渲染。仅页签条使用 `workspace-tab-bar` tokens 类，内容区只以直接子选择器约束剩余高度；页面内 Tabs 不继承框架的尺寸与颜色。框架页签为 14px 正文字号（2026-10-20 由 12px 调大），图标同步使用标准图标尺寸，侧栏为 14px 正文字号，品牌字为 16px；品牌图形保留原有四块菱形构造，装饰尺寸集中在 tokens 中。导航链接仍使用路由链接以保留浏览器链接行为，操作按钮使用 Ant Design。

U2 列表统一使用 `PanelToolbar` 与 Ant Design Table；目录的名称仍用路由链接进入详情。设置页各小节为同宽的并列 `Panel`，标题放入 `PanelToolbar`，表单区使用 16px 内边距；表格直接贴合面板边缘，保持首列与标题对齐。发布页使用一个 `Panel`，通过 Tabs 的 `renderTabBar` 将页签条放入 `PanelToolbar` 的 `tabBar` 插槽，保持原有页签内容与保活行为；该插槽不增加内部包装，保留 Ant Design 对导航条直接父级的选择器约束。服务接入按分割线分区，各区使用 `SectionTitle`，不再嵌套卡片。目录主体和设置面板的最大宽度集中在 tokens；面板不沿页面纵向收缩，溢出由 `PageBody` 滚动承接。

U3 发布与提案沿用面板内分区模式：发布上下文与检查结果在现有发布面板内以分割线分区，不再增加 Card；变更列表使用无外框的 Collapse。构建结果使用单个 `Panel fill` 填满剩余高度，目录等页面继续使用默认的内容高度；页签置于 `PanelToolbar`；提案状态（2026-10-20 恢复改造前样式）使用 12px 下划线小页签独占一行，数量为辅助色，冲突数大于 0 时整项用危险色；下一行搜索框占满剩余宽度、类型多选在右，批量操作另占一行；列表条目只保留底部分割线。提案详情、冲突三方内容与证据使用 `SectionTitle` 配合无边框 Descriptions、Table 或引用文本组织，同级内容用分割线分区，不套卡片。详情滚动高度、证据弹层宽度及 JSON 预览高度沿用既有尺寸并集中到 tokens；构建结果 Tabs 的剩余高度约束只作用于直接子级，避免影响内部页签。

本体浏览与目录（2026-10-19，当前生效）：本体视图直接显示语义图和资源管理器，删除全局分层总览及全局/语义切换。本体对象目录采用实体 / 关系 / 指标三个 Ant Design Tabs，标签显示真实数量；复用 PanelToolbar，将筛选、搜索和当前类别的新建放在同一工具栏，保持紧凑 Table 密度。右上角集中导入、导出、发布，复用已有弹窗和发布预检页。侧栏移除本体关系、本体发布，旧地址继续可达或转入关系 Tab；此调整不新增容器层级、模型字段或视觉数值。

语义视图画布（2026-10-19）：移除重复显示选中项名称的浮动条；选中通过资源树与图节点/关系高亮表达，详情继续从双击或资源菜单打开，点击画布空白处清除选择。资源管理器收起后不保留白色侧栏或占位宽度，图谱填满释放空间；画布左上角只保留一个 Ant Design 展开按钮。指标/数据集列表模式将该按钮放在列表工具栏，避免遮挡表格。展开后恢复原筛选、选择与分组状态。沿用 top-4/left-4、既有按钮和字号间距档位，不新增视觉变量。

构建草稿与会话入口（2026-10-19）：模型分类恢复为图标、名称、真实数量组成的 Ant Design 网格按钮，替代横向分段切换器；图标使用既有语义色及柔和背景，选中态使用蓝色边框，不套 Card。网格按结果容器宽度自动换列，最小宽度由 tokens.css 的 model-category-min-width 管理，每行最多 model-category-max-columns（4）个（2026-10-20）；结果栏宽度由 builder-results-width 控制（30%，340–480px），对话区占剩余宽度；草稿表格的说明最多两行，超出部分悬停查看，按钮沿用 px-2/py-2、text-xs、rounded-md，分类后搜索框与发布按钮同行。保留当前核心模型全部分类，包括文档事实和文档关系。

会话历史、新建移入中间对话面板工具栏右侧，使用历史和加号图标。历史打开 Ant Design Modal，搜索和表格占满弹窗正文，复用会话搜索、状态及更新时间表，不在页面顶部展示会话选择器。发布入口移至本体草稿的搜索框右侧，与搜索同行且不收缩，仅在该页签显示；需已有提案批次、草稿与基线存在差异且非运行/忙碌时启用，仍进入原发布预检页，不直接发布。

构建输入区场景（2026-10-19）：使用 SDK 公开 composer-actions 插槽，在输入框底部左侧以 Ant Design 加号 Dropdown 选择本体建模/本体查询，旁边显示当前场景，右侧统一发送图标，不随场景改变按钮名称。移除左侧开始建模按钮；运行时保留 SDK 停止操作。插槽容器采用 flex、min-w-0、gap-2、text-xs，复用现有色彩/间距/字号，无新增视觉数值；通过公开 actions/send-button Part 分配宽度并避免重复发送按钮。

数据管理（2026-10-19）：原数据映射页采用数据集/文档两个同级页签，文档使用紧凑 Table、使用状态 Tag、搜索和筛选；展开行展示补充统计及引用位置。复用 PanelToolbar、gap-2/gap-4、text-xs 和已有 Ant Design 控件，不增加容器层级或视觉变量。操作失败通过 App.useApp().message 浮动显示，不在正文插入错误条；首次加载导致页面无法显示的故障仍可保留带重试的错误面板，表单字段校验及业务告警按原位置保留。构建页顶部不放 DataAgent 配置提示，发送按钮 Tooltip 说明禁用原因。

## 5. 约束机制

### 5.1 lint 规则

在 `apps/web/eslint.config.js` 的 `no-restricted-syntax` 中增加，对 `src/**/*.tsx`（测试除外）生效：

- 禁止 Tailwind 任意值：`className` 中出现 `-[...]`；
- 禁止 `!` 强制覆盖：`className` 中出现以 `!` 开头的类；
- 禁止 `style=` 内联样式；
- 禁止在组件代码里写颜色值（`#xxxxxx`、`rgb(`、`hsl(`）；
- 禁止给 `Tag` 传 `color` 表示状态（状态走 `StatusMark`）。

例外只允许出现在第 7 节例外表列出的文件，以文件级配置声明，不在代码里逐行关闭。

推广期间规则按“已改造文件为 error、其余为 warn”配置，全部页面完成后统一改为 error。

### 5.2 截图比对

新增 Playwright 截图测试（`@playwright/test`，固定版本），在固定窗口 1440×900、固定虚构示例数据下，对已改造页面截图并与基准比对。基准图提交到仓库；更新基准必须在评审中说明原因并经人确认。

### 5.3 协作约定

在 `AGENTS.md` 的前端约定中增加：

- 界面改动只用 `components/layout/` 和 Ant Design 控件拼装，视觉数值只改 `tokens.css`；
- 每次界面改动提交前，对受影响页面在 1440×900 下截图，与基准或改前截图对比，并对照本文第 3 节逐项检查：容器层级、对齐线、字号档位、状态显示、表格密度；
- 新布局模式先补本文第 4 节。

| 范围 | 例外内容 | 原因 |
