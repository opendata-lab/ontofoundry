# 界面视觉一致性：还原原有视觉语言并固化为约束

状态：已确认（2026-10-17 选定方向 A）

共识更新：2026-10-19 将跨产品共识集中到 [企业 ToB 产品界面设计共识](2026-10-19-tob-ui-design-principles.md)，本文维护当前项目的视觉实现规则。

## 1. 背景

core-1 P0 起前端改用 Ant Design 5 + Tailwind CSS v4。功能迁移完成后，整体观感不如原来：

- 页面没有统一的容器层级，页签、筛选、搜索和表格分散铺在背景上；
- 左边缘不对齐，同一页面里标题、页签、表格首列各在一条线上；
- 字号 13/14/15/22px 混用，按钮是胶囊圆角而输入框是小圆角；
- 状态用粗进度条加撑满整列的带框标签，视觉重心落在状态上；
- 行高变大，信息密度下降。

原因不在组件库。组件库只提供控件，不规定“怎么组装”：容器层级、对齐线、字号和间距档位、状态显示方式、表格密度。这层规则没有写下来，各次生成各自决定；同时存在 `tokens.css`、Ant Design 主题覆盖、Tailwind 任意值和 `!` 强制覆盖三套样式来源；验收只验证功能，不比对视觉。

2026-10-17 在数据映射页并排试验了两个方向：A 在 Ant Design 上还原原有视觉语言，B 采用 Ant Design Pro 标准中后台风格。A 更紧凑、对齐更干净，最接近原来的专业感，选定 A。

## 3. 视觉规则

### 3.1 颜色

| 用途 | 变量 | 说明 |
|---|---|---|
| 画布 | `--color-canvas` | 页面底层背景 |
| 面板 | `--color-surface` | 面板、输入框、表格主体 |
| 表头/悬停 | `--color-surface-raised` | 表头、行悬停、面板底注 |
| 柔和填充 | `--color-surface-soft` | 分段筛选轨道、默认标签底 |
| 分割线 | `--color-rule-soft` / `--color-rule` / `--color-rule-strong` | 弱分割、标准边框、悬停强调 |
| 文字 | `--color-ink` / `--color-ink-2` / `--color-muted` / `--color-subtle` | 标题、正文、辅助、占位 |
| 品牌 | `--color-accent` / `--color-accent-soft` | 主按钮、激活页签、链接 |
| 语义 | `--color-success` / `--color-warning` / `--color-danger`（含 `-soft`） | 状态文字与图标；成功色用深绿 |

### 3.2 尺寸档位

| 项 | 档位 |
|---|---|
| 字号 | 12px（表头、技术名、状态、标签、辅助说明）、13px（正文、控件、页签、小节标题）、16px（页面与弹窗标题），不允许第 4 档 |
| 行高 | 1.35（小字与标题）、1.45（正文与表格） |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24px |
| 圆角 | 4px（小号控件、标签）、6px（按钮、输入框、下拉框）、8px（面板、卡片、弹窗）；不使用胶囊圆角 |
| 控件高度 | 28px（面板工具栏内）、32px（标准）、36px（特殊强调） |
| 表格 | 单元格 10px × 16px，紧凑表格 8px × 12px；表头 12px、辅助色、无竖分割线 |

### 3.3 容器与对齐

- 页面最多两层容器：画布 → 白色面板。面板内用分割线分区，不再套卡片。
- 页面级对齐线：页面左右内边距 24px，页头标题与面板外框左边缘对齐，页头动作按钮与面板右边缘对齐。
- 面板内对齐线：16px，面板工具栏、表格首列、底部说明左边缘对齐。
- 页签、状态筛选、搜索放在面板顶部同一行。

### 3.4 状态显示

- 状态统一用 `StatusMark`：语义色小图标 + 12px 文字，不加背景框和边框；不用带颜色的 `Tag` 表示状态。
- 覆盖率：12px 比例文字 + 56px 宽、4px 高的细进度条，下接 `StatusMark`。

## 4. 布局组件

位于 `apps/web/src/components/layout/`，页面只用这些组件和 Ant Design 控件拼装：

| 组件 | 用途 |
|---|---|
| `PageHeader` / `PageBody` | 页头（16px 标题、副标题、右侧动作）与滚动主体，共用 24px 对齐线 |
| `Panel` | 白色面板，可带底部说明栏 |
| `PanelToolbar` | 面板顶部工具栏：左侧页签或主筛选，右侧状态筛选与搜索；详情正文使用 `inset={false}` 与表格左边缘对齐 |
| `StatusMark` | 唯一的状态显示方式 |
| `SectionTitle` | 面板或弹窗内的 13px 小节标题，可带附注和右侧操作 |
| `FormRow` | 相关表单字段等宽并排，窄容器切回单列 |
| `DetailWorkbench` | 详情弹窗中的紧凑列表与选中项配置区；支持窄容器上下排列 |
| `ApplicationFrame` | U1 应用框架：顶栏、可收起侧栏和剩余高度的页面区域；沿用原有窄屏整体缩放 |
| `AsyncSurface` | U1 加载与错误反馈的 24px 内边距；整页路由错误居中，不额外嵌套面板 |
| `DirectoryFrame` | U2 工作空间目录的独立顶栏与居中主体，主体内继续使用 `PageHeader` / `PageBody`，宽度与顶栏高度引用 tokens |

U1 框架页签采用 Ant Design editable-card Tabs，页面仍通过 items.children 渲染。仅页签条使用 `workspace-tab-bar` tokens 类，内容区只以直接子选择器约束剩余高度；页面内 Tabs 不继承框架的尺寸与颜色。框架页签为 12px 辅助字号，侧栏为 13px 正文字号，品牌字为 16px；品牌图形保留原有四块菱形构造，装饰尺寸集中在 tokens 中。导航链接仍使用路由链接以保留浏览器链接行为，操作按钮使用 Ant Design。

U2 列表统一使用 `PanelToolbar` 与 Ant Design Table；目录的名称仍用路由链接进入详情。设置页各小节为同宽的并列 `Panel`，标题放入 `PanelToolbar`，表单区使用 16px 内边距；表格直接贴合面板边缘，保持首列与标题对齐。发布页使用一个 `Panel`，通过 Tabs 的 `renderTabBar` 将页签条放入 `PanelToolbar` 的 `tabBar` 插槽，保持原有页签内容与保活行为；该插槽不增加内部包装，保留 Ant Design 对导航条直接父级的选择器约束。服务接入按分割线分区，各区使用 `SectionTitle`，不再嵌套卡片。目录主体和设置面板的最大宽度集中在 tokens；面板不沿页面纵向收缩，溢出由 `PageBody` 滚动承接。

U3 发布与提案沿用面板内分区模式：发布上下文与检查结果在现有发布面板内以分割线分区，不再增加 Card；变更列表使用无外框的 Collapse。构建结果使用单个 `Panel fill` 填满剩余高度，目录等页面继续使用默认的内容高度；页签置于 `PanelToolbar`，提案状态、类型筛选与搜索共用工具栏，窄面板内按控件组换行，批量操作另占一行；列表条目只保留底部分割线。提案详情、冲突三方内容与证据使用 `SectionTitle` 配合无边框 Descriptions、Table 或引用文本组织，同级内容用分割线分区，不套卡片。详情滚动高度、证据弹层宽度及 JSON 预览高度沿用既有尺寸并集中到 tokens；构建结果 Tabs 的剩余高度约束只作用于直接子级，避免影响内部页签。

本体浏览与目录（2026-10-19，当前生效）：本体视图直接显示语义图和资源管理器，删除全局分层总览及全局/语义切换。本体对象目录采用实体 / 关系 / 指标三个 Ant Design Tabs，标签显示真实数量；复用 PanelToolbar，将筛选、搜索和当前类别的新建放在同一工具栏，保持紧凑 Table 密度。右上角集中导入、导出、发布，复用已有弹窗和发布预检页。侧栏移除本体关系、本体发布，旧地址继续可达或转入关系 Tab；此调整不新增容器层级、模型字段或视觉数值。

语义视图画布（2026-10-19）：移除重复显示选中项名称的浮动条；选中通过资源树与图节点/关系高亮表达，详情继续从双击或资源菜单打开，点击画布空白处清除选择。资源管理器收起后不保留白色侧栏或占位宽度，图谱填满释放空间；画布左上角只保留一个 Ant Design 展开按钮。指标/数据集列表模式将该按钮放在列表工具栏，避免遮挡表格。展开后恢复原筛选、选择与分组状态。沿用 top-4/left-4、既有按钮和字号间距档位，不新增视觉变量。

构建草稿与会话入口（2026-10-19）：模型分类恢复为图标、名称、真实数量组成的 Ant Design 网格按钮，替代横向分段切换器；图标使用既有语义色及柔和背景，选中态使用蓝色边框，不套 Card。网格按结果容器宽度自动换列，最小宽度由 tokens.css 的 model-category-min-width 管理，按钮沿用 px-2/py-2、text-xs、rounded-md，分类后搜索框与发布按钮同行。保留当前核心模型全部分类，包括文档事实和文档关系。

会话历史、新建移入中间对话面板工具栏右侧，使用历史和加号图标。历史打开 Ant Design Modal，搜索和表格占满弹窗正文，复用会话搜索、状态及更新时间表，不在页面顶部展示会话选择器。发布入口移至本体草稿的搜索框右侧，与搜索同行且不收缩，仅在该页签显示；需已有提案批次、草稿与基线存在差异且非运行/忙碌时启用，仍进入原发布预检页，不直接发布。

构建输入区场景（2026-10-19）：使用 SDK 公开 composer-actions 插槽，在输入框底部左侧以 Ant Design 加号 Dropdown 选择本体建模/本体查询，旁边显示当前场景，右侧统一发送图标，不随场景改变按钮名称。移除左侧开始建模按钮；运行时保留 SDK 停止操作。插槽容器采用 flex、min-w-0、gap-2、text-xs，复用现有色彩/间距/字号，无新增视觉数值；通过公开 actions/send-button Part 分配宽度并避免重复发送按钮。

数据管理（2026-10-19）：原数据映射页采用数据集/文档两个同级页签，文档使用紧凑 Table、使用状态 Tag、搜索和筛选；展开行展示补充统计及引用位置。复用 PanelToolbar、gap-2/gap-4、text-xs 和已有 Ant Design 控件，不增加容器层级或视觉变量。操作失败通过 App.useApp().message 浮动显示，不在正文插入错误条；首次加载导致页面无法显示的故障仍可保留带重试的错误面板，表单字段校验及业务告警按原位置保留。构建页顶部不放 DataAgent 配置提示，发送按钮 Tooltip 说明禁用原因。

U4 元素详情弹窗沿用 Ant Design Modal 的头部和关闭按钮，标题使用 16px，技术名、端点与状态为 12px 辅助行；编辑、复制链接和展开操作在标题右侧。进入编辑后，原“编辑”按钮位置显示“取消”“保存”，不设置底部操作栏。弹窗自身为白色容器，页签置于 `PanelToolbar`，正文采用 16px 内对齐线，不在弹窗中再套 `Panel` 或 Card。宽度复用应用最小工作宽度，展开时占满可用宽度。

2026-10-19 确认统一外框：同一窗口尺寸下，弹窗高度不随页签内容或查看/编辑状态变化。普通模式内容容器高 800px，并受视口上下各 24px 的边距约束；展开模式上下各留 8px。尺寸集中在 `tokens.css` 的 `--inspector-height`、`--inspector-expanded-height`，不再借用正文预览的最大高度。内容容器纵向排布，头部保留 48px 最小高度，页签不收缩；正文填充剩余空间并独立滚动。固定尺寸框架与顶部原位取消/保存均已实现，进入编辑时不再额外压缩正文。内部页签使用全量方案统一确认；按用户安排暂不运行测试、构建或截图验收，既有弹窗截图基准待集中验证时更新。

详情键值区使用无边框的紧凑 Descriptions，默认双列展示，长说明或成员条件占整行。对象概览在 2026-10-19 确认采用左侧约 40% 基础信息、右侧约 60% 关系图：基础信息改为单列“标签＋值”，长内容自然换行；两侧使用 `SectionTitle`，标题行最小高度 28px，标题与内容间距 8px，列间距 24px。布局按弹窗正文容器宽度切换，至少 48rem 时使用 2:3 两列，否则回到单列；关系图高度为 480px，以扩大节点和文字的可视尺寸。比例和高度由 `tokens.css` 的 `--inspector-overview-columns`、`--inspector-overview-graph-height` 管理。此项只调整对象概览的查看布局，编辑表单和其他页签另行确认。

小节用 `SectionTitle`，同级内容用分割线分区；来源证据使用引用区。表格直接放在正文对齐线上，使用紧凑密度；表格内编辑行使用小号 Ant Design 控件，复杂条件与来源编辑使用等分网格、弹性控件和固定操作按钮，不另加外框。属性与映射使用 `DetailWorkbench`：列表约 55%、配置区约 45%，按容器宽度在 40rem 以下切为上下排列；列表显示名称、技术名、类型及约束，选中行使用强调色柔和背景，配置区分基本信息、约束和绑定三段。对应比例由 `--inspector-property-columns` 管理。关系和规则复用 `DetailWorkbench` 的列表/详情布局，详情按业务含义分组；实例工具栏复用 `PanelToolbar`，来源使用下拉单选文档或数据库，不合并展示且不重复添加来源列，选中实例在右侧预览，收起后列表恢复全宽。实例预览使用约 60% / 40% 分配，宽度由 `--inspector-preview-columns` 管理，表格最小宽度由 `--inspector-results-table-min-width` 管理；窄容器改为上下排列。指标总值使用 16px 文字，趋势和查询继续使用 Table 与 Tabs。顶部操作区统一管理编辑、取消与保存；保存影响确认使用无外框 List 和中性类型标签，语义状态统一使用 `StatusMark`。保留 ConfigProvider 的忙碌禁用、预检确认与草稿变化后的重新预检。

构建配置侧栏（2026-10-19）：按业务场景标签、业务知识、业务数据、业务场景描述依次纵向组织。“选择数据表”只属于业务数据分区，不进入文件上传框。侧栏正文独立滚动，分区 shrink-0 保持内容自然高度，小节采用 flex-col/gap-3、分区间 gap-4，沿用现有间距档位。Upload.Dragger 通过 Tailwind 取消内部百分比高度，按内容撑开，避免溢出覆盖下一分区；不新增像素值或样式文件。上传及已有材料切换、数据表选择和建模行为保持原样。

U6 文件导入沿用 U4 详情弹窗模式：Ant Design Steps 放在顶部，格式与文件选择用垂直 Form 和受控 Upload。报告在正文用紧凑 Table，展开行以 Descriptions 和 Typography 展示来源、行号与原文；同级内容用分割线分区，不套卡片。状态复用 StatusMark，待补全用 Collapse、可搜索 Select 或来源定义编辑框，确认按钮放底部右侧。宽度、滚动高度均复用已有详情和预览档位，不新增视觉变量。导入、导出、发布统一位于本体对象页右上角，构建页和本体视图不再重复提供导入入口；确认导入后进入对应构建会话的提案页，导入会话的报告入口放在提案工具栏。

U7 导出复用 U4/U6 弹窗和报告布局，版本与格式用双列 Form 和可搜索版本 Select；校验错误使用 Alert，底部报告生成和同产物下载按钮右对齐。历史表增加同级操作列，版本比较工具栏增加目标版本导出入口，不新增容器或视觉变量。

推广中如需新的布局模式（如详情弹窗的键值区、空状态），先加入本节并获确认，再在页面中使用。

关系详情模式（2026-10-19，最新确认）：采用概览 / 映射 / 规则三个页签。概览以两端对象选择、正反向语义行、无边框 Descriptions 和下方实例表展示关系及实例，编辑定义使用 FormRow；原实例页签内容移入概览。映射页关闭使用映射表开关时不出现配置表单，开启后才展示来源表及两端列对应；已有属性直连在概览维护。规则使用独立任务页，不放“其他设置”。复用 FormRow 等宽双列布局，在正文容器不足 40rem 时回到单列；间距沿用 tokens。关系与对象详情共用宽高及展开规则。正反向语义复用 FormRow 等宽排列，各自用 SectionTitle、自然语言数量行和方向名称组织，不套 Card；数量控件宽度引用 tokens 的 inspector-cardinality 档位。两端对象下方使用 FormRow 编辑两端角色名，方向标题及数量行优先展示所到达端的角色，空值回退关系标识或对象名称。关系标识只在标题显示、编辑时在基本信息输入，不在查看正文重复；无描述/同义词/标签时省略基本信息。对象关联区改称关系详情，关系实例来源列直接显示文档，取消固定来源工具栏文字。正反数量行下分别展示完整关系含义；编辑复用 Ant Design Input.TextArea 与原有 gap/text-xs 档位，提供中文占位符及渲染预览，不增加视觉数值。

## 5. 约束机制

### 5.1 lint 规则

在 `apps/web/eslint.config.js` 的 `no-restricted-syntax` 中增加，对 `src/**/*.tsx`（测试除外）生效：

- 禁止 Tailwind 任意值：`className` 中出现 `-[...]`；
- 禁止 `!` 强制覆盖：`className` 中出现以 `!` 开头的类；
- 禁止 `style=` 内联样式；
- 禁止在组件代码里写颜色值（`#xxxxxx`、`rgb(`、`hsl(`）；
- 禁止给 `Tag` 传 `color` 表示状态（状态走 `StatusMark`）。

例外只允许出现在第 7 节例外表列出的文件，以文件级配置声明，不在代码里逐行关闭。

推广期间规则按“已改造文件为 error、其余为 warn”配置，全部页面完成后统一改为 error。

### 5.2 截图比对

新增 Playwright 截图测试（`@playwright/test`，固定版本），在固定窗口 1440×900、固定虚构示例数据下，对已改造页面截图并与基准比对。基准图提交到仓库；更新基准必须在评审中说明原因并经人确认。

### 5.3 协作约定

在 `AGENTS.md` 的前端约定中增加：

- 界面改动只用 `components/layout/` 和 Ant Design 控件拼装，视觉数值只改 `tokens.css`；
- 每次界面改动提交前，对受影响页面在 1440×900 下截图，与基准或改前截图对比，并对照本文第 3 节逐项检查：容器层级、对齐线、字号档位、状态显示、表格密度；
- 新布局模式先补本文第 4 节。

## 6. 推广范围与顺序

见计划 `docs/plans/2026-10-17-ui-visual-consistency-plan.md`。原则：先框架和基础，再列表页，最后弹窗和画布类页面；每批由用户确认标杆页后再继续。

## 7. 例外

| 范围 | 例外内容 | 原因 |
|---|---|---|
| 图谱画布（`OntologyGraph`、`ObjectRelationGraph`、语义视图画布） | 允许 `style=` 设置节点位置和尺寸 | 由 xyflow 计算的动态坐标，无法用固定类表达 |
| `Markdown` 渲染 | 允许为渲染内容设置排版类 | 渲染外部文本，需要独立排版规则 |

## 8. 不在本次范围

- 功能、数据、接口和文案含义不变；
- 暗色主题；
- 品牌标识重新设计。
