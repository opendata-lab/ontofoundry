# 构建对话输入区与场景

状态：已确认并实施；按用户要求暂不运行测试。

## 已确认决定

| 主题 | 决定 |
|---|---|
| 主操作位置 | 移除左侧“开始建模”，主操作移至中间对话输入框内底部右侧 |
| 场景入口 | 输入框底部左侧加号打开 Ant Design Dropdown，场景分组包含“本体建模”和“本体查询”，显示当前选项 |
| 默认场景 | 本体建模；输入提示随场景变化，当前场景在加号旁以蓝色 Ant Design Tag 显示 |
| 统一发送 | 两种场景共用发送图标按钮，不切换按钮名称；Tooltip 与可访问名称均为“发送” |
| 建模行为 | 复用现有 model 模式生成提案；材料、业务场景描述或输入框需求任一非空即可开始，仍受连接配置和运行状态约束 |
| 查询行为 | 复用现有 chat 模式，基于会话当前本体进行问答，不生成提案；本次不新增数据库查询能力或 Agent 配置 |
| 一致性 | 按钮提交和 SDK 自带提交路径都按所选场景发送；运行时保留 SDK 停止操作，禁止切换场景 |
| 输入区实现 | 使用 SDK 公开 composer-actions 插槽和 Shadow Parts，控件使用 Ant Design；不替换 SDK 文本输入和消息组件 |

场景是用户指定的界面操作选择，复用已有 model/chat 通路；不属于本体业务模型，不新增字段、接口或持久化模式。左侧继续提供材料及业务场景描述，切换场景不清除输入内容。

后续反馈修订：构建页标题区移除 DataAgent 配置链接，发送按钮禁用时通过 Tooltip 说明配置/上传/忙碌原因；操作错误改为浮动消息。等待用户回答的业务提示保留在对话上下文附近。
