# PR #23 第四轮修正设计

本轮修复既有契约实现，不新增模型字段、状态或模式，不改变核心业务语义。继承范围沿用核心模型已确认决定 D3b，来源为现有 Ossie 兼容设计；编辑期 UUID 绑定缓存属于界面临时状态，不写入核心模型。

## 已确认决定

| 项目 | 修正 |
|---|---|
| F1 | 编辑期间以属性 UUID 保持绑定；技术名重复时不写入冲突键，最终名称唯一后统一重建映射字典。编辑缓存随弹窗编辑生命周期保留。 |
| F2 | 事实值的精确最终形式比较同时核对容器结构、标量类型和值，区分布尔、整数和浮点数。 |
| F3 | 会话补入目标依赖时，按核心继承规则包含属性、普通关系、规则和有效映射，再遍历其引用依赖；已有草稿不覆盖，不补指标、事实或无关子类。补入项参与确认，hash 来源沿用预检计算。 |
| F4 | 条件编辑按列类型解释值：文本原文、布尔选择、数字解析、日期字符串。切列保留已有值并重新校验类型，错误阻止保存。 |
| A1 | 映射和事实键以精确最终形式优先；同一请求存在解释歧义时按最终形式接受，同时改名和改绑定须分两次保存。 |

不修改 Schema、迁移或外部 Agent。前端使用 Ant Design 控件，验证遵循任务指定的全量命令，不启动应用服务。
