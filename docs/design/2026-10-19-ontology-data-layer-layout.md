# 本体总览的数据来源并列布局

状态：已由后续“移除全局总览”决定替代，不作为当前页面方案。

## 已确认决定

| 主题 | 决定 |
|---|---|
| 层级 | 服务层、语义模型层、数据来源层，共三个层级 |
| 数据来源 | 原实例与证据、数据映射不再表示上下游层级，改为同一级的非结构化数据与结构化数据 |
| 左侧摘要 | 数据来源层中并排显示两类来源，分别保留文档实例/实例关系/来源材料、对象映射/数据集的现有计数及入口 |
| 右侧图示 | 两个数据来源平面并排、同一高度，位于语义模型层下面，保留原节点和打开详情行为 |
| 语义边界 | 只调整信息组织，不修改模型、权限、统计定义或数据读取；不新增结构化/非结构化持久化标志 |
| 视觉 | 沿用现有颜色、字号、平面风格；布局与 SVG 几何数值集中到 tokens.css |
| 验证 | 仅人工查看，不运行测试、构建或 lint |

分类是当前总览的展示分组，文档实例仍为已有文档事实，结构化数据仍为已登记数据集及其映射，不把两类来源画成先后依赖。

## 后续决定（当前生效）

用户随后明确删除整个全局总览，突出本体语义浏览。因此上述三层图及并列来源平面不再实施到页面，相关未交付图示改动已撤回；本体视图直接使用语义图与资源管理器，不保留全局/语义切换。本轮仍完成语义图浮动条和收起白栏的精简。
