# 保证金账户冻结管理办法（节选）

为防范结算风险，交易所可对结算会员的专用资金账户实施冻结。本办法说明冻结业务涉及的对象、关系与要求。

## 一、账户冻结记录

账户冻结记录是交易所对某一专用资金账户实施的一次冻结措施。

- **冻结编号**：冻结记录的唯一标识，由交易所编制。
- **冻结原因**：例如结算违约、保证金不足、司法协助。
- **冻结金额**：本次冻结的资金金额，单位为人民币元。
- **冻结日期**：冻结措施生效的日期。
- **解冻日期**：冻结解除的日期，尚未解除时为空。
- **冻结状态**：取值为“冻结中”“已解冻”。

## 二、关系

- 每条账户冻结记录**针对**一个专用资金账户；一个专用资金账户可以有多条冻结记录。
- 每条账户冻结记录由**金融期货交易所**发起。
- 冻结记录**涉及**该专用资金账户所属的结算会员。

## 三、规则

1. 冻结金额必须大于 0。
2. 冻结状态为“已解冻”时，必须有解冻日期，且解冻日期不早于冻结日期。
3. 同一专用资金账户在同一时间最多只能有一条“冻结中”的记录。
