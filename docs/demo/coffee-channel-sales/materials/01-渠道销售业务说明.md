# 咖啡渠道销售业务说明

本公司经营精品咖啡及咖啡器具，通过渠道客户（零售门店、商超、咖啡馆、文创店等）进行批量分销。本文说明渠道销售业务中的核心业务对象、它们之间的关系，以及统计口径。

## 一、客户

客户指与本公司签约、按批次采购商品的渠道企业。

- **客户编号**：客户的唯一标识，由系统自动分配。
- **客户名称**：签约企业的名称，例如“星海贸易”“远山咖啡”。
- **所在城市**：客户主要经营所在的城市。
- **签约日期**：客户与本公司完成签约、开始合作的日期。

一个客户可以多次下单。

## 二、订单

订单是客户向本公司发起的一次采购。

- **订单编号**：订单的唯一标识。
- **下单时间**：客户提交订单的时间。
- **订单状态**：订单当前所处的状态，取值为“已支付（paid）”或“已发货（shipped）”。
- **订单金额**：订单应收总金额，单位为人民币元，等于该订单全部订单明细的明细金额之和。

每张订单必须属于且只属于一个客户。一张订单包含一条或多条订单明细。

## 三、商品

商品是本公司对外销售的标准品。

- **商品编号**：商品的唯一标识。
- **商品名称**：例如“经典手冲壶”“精品拼配豆”。
- **商品品类**：商品所属的品类，例如咖啡器具、咖啡豆、饮品、耗材、周边。
- **标准单价**：商品的标准销售单价，单位为人民币元。

## 四、订单明细

订单明细记录一张订单中某一种商品的购买情况。

- **明细编号**：订单明细的唯一标识。
- **购买数量**：该商品的购买件数，必须大于 0。
- **成交单价**：本次成交的单价，单位为人民币元。
- **明细金额**：成交单价乘以购买数量。

每条订单明细属于一张订单，并且对应一种商品。

## 五、业务关系汇总

| 关系 | 说明 |
| --- | --- |
| 客户 —下单→ 订单 | 一个客户可以下多张订单，一张订单只属于一个客户 |
| 订单 —包含→ 订单明细 | 一张订单包含多条订单明细 |
| 订单明细 —对应→ 商品 | 每条订单明细对应一种商品 |

## 六、业务规则

1. 订单金额等于该订单所有订单明细的明细金额之和。
2. 明细金额等于成交单价乘以购买数量。
3. 购买数量必须大于 0。
4. 只有“已支付”的订单才能变更为“已发货”。

## 七、常见分析口径

- **客户销售额**：某客户全部订单的订单金额之和。
- **城市销售额**：按客户所在城市汇总的订单金额。
- **商品销量**：某商品在全部订单明细中的购买数量之和。
