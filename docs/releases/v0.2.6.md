# v0.2.6

日期：2026-11-02。基于 v0.2.5 之后的主干修复，平台和 DataAgent 技能成套发布。

## 修复与变化

- 生成最终结果前必须通过平台预检。本地格式检查通过后，平台继续检查表达式、引用、候选图和材料证据；连接失败或检查未通过时不写最终结果，避免把本地检查通过误报为可交付。
- 预检、入库、修订和接受复用同一个试应用入口。一批提案整批通过或整批拒收，运行内最多修正两轮。
- 建模会话串行处理。运行中、结果处理中或仍有待审提案时，不能启动新一轮或直接编辑草稿；先处理待审提案，或在提案上修订。
- 新概念范围通过 DataAgent 的问题卡片和计划卡片确认，计划批准后继续抽取。只生成供用户审阅的提案，不自动接受或发布本体。
- 对话建模需求可保存为材料并引用为实例证据；改进材料哈希补全、增量查找与子对象共用父表读取。
- API、前端及插件版本统一为 0.2.6。Release 提供平台离线包，配套技能另以一个 ZIP 交付，包含三个独立技能 ZIP、管理员插件 ZIP、升级说明及校验和。

## 升级顺序

1. 停止旧建模运行，备份平台数据库、文件卷、技能目录以及已有 Agent 的配置。
2. 升级平台镜像。平台启动时自动执行 Alembic 迁移至 `20261026_000001`。本次不是无迁移升级：迁移删除旧的“不可接受”提案和失败批次，将“被取代”的提案、以及已开启新一轮的旧批次待审提案改为已拒绝。
3. DataAgent 需为 main `6f2bf6e8` 或更新，数据库迁移至 `20261026_000029`，支持问题卡片、计划卡片和计划模式。平台安装包不包含 DataAgent 运行时。
4. 完整替换三个技能目录，停用并备份移走旧 `ontofoundry-modeling`。核对管理员包内两个已有 Agent 的提示词和技能挂载，更新并发布；建模 Agent 的计划等待超时设置为“继续等待用户确认”。重启 DataAgent。
5. 从 DataAgent 所在环境确认可访问平台 `public_base_url`，然后用新会话验收。合并时应先显示“平台检查通过”，再保存最终结果；用户仍须审阅提案。

离线包解压后的平台 README 与本页的技能升级说明配合使用。更详细的安装步骤见 [三技能迁移说明](../../integrations/dataagent/迁移说明.md)。

## 回退

保留 v0.2.5 的镜像与升级前备份。如需回退，停止新运行，成套恢复升级前数据库、文件、平台镜像、技能目录和 Agent 配置，再启动服务。不能只降级镜像：旧提案状态清理迁移无法自动还原被删除的记录。
