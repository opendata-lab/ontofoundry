# v0.5.0

日期：2026-11-18。基于 v0.4.1 之后的主干（#100、#101）：空间设置页重做，DataAgent 连通性检查改为平台级、仅平台管理员可用；README 改版并新增英文版。设计见 `docs/design/2026-11-17-workspace-settings-and-dataagent-health.md`。

## 行为变化（升级前请读）

- **DataAgent 连通性检查的地址和权限都改了，没有转发。** 原 `GET /api/v1/workspaces/<空间>/settings/dataagent-health` 取消，改为 `GET /api/v1/system/dataagent-health`，仅平台管理员可调：未登录返回 401，非平台管理员返回 403。检查结果含 DataAgent 内部地址、`website_id` 与 `agent_id`，因此不再对空间管理员开放。默认 `dev` 模式下的 `dev` 用户是平台管理员。
- **空间设置页不再显示 DataAgent 连通性。** 构建页在 DataAgent 未配置时提示“DataAgent 建模服务未配置，请联系部署管理员”。
- **`compose.yaml` 显式列出** `ONTOFOUNDRY_CORS_ORIGINS`、`ONTOFOUNDRY_PUBLIC_BASE_URL`、`ONTOFOUNDRY_MCP_TOKEN`，可在 `.env` 中覆盖；默认行为不变。`ONTOFOUNDRY_MCP_TOKEN` 的默认值是公开的，正式环境须改为至少 24 字符的随机值，不用单空间 MCP 时设为空。

## 新功能与改进

- **空间设置页重做：** 全宽两栏。空间信息可改名称和说明（改动后才能保存或重置，保存后显示“已保存”），空间标识可复制，公开开关需确认。成员列表只有用户名、角色、操作三列；“添加成员”在表格上方内联展开，按用户名搜索已有用户；改角色、移除成员都有确认，保留“至少一名管理员”的保护。
- **出错时的提示更准确：** 设为公开失败时确认框保持打开；搜索用户失败时显示失败原因，不再说“用户不存在”；成员加载失败时不显示人数，也不能添加；在候选下拉中按回车选中所选用户，不再按输入到一半的文字添加。
- **README 改版，新增英文版 `README.en.md`、品牌标识和 `docs/deployment.md`**（部署、升级与安全要点）。

## 验证

- 后端测试 1689 通过；前端类型检查、构建通过；设置页测试全部通过，空间设置截图（1440×900）与基准一致。
- 局域网 IP 的 HTTP 访问（非安全上下文）下，复制空间标识和添加成员正常（#100 作者验证）。

## 升级顺序

1. 备份平台数据库和文件卷。
2. 使用 v0.5.0 离线包的 `compose.yaml` 与镜像升级并启动。**本版没有数据库迁移**；`.env` 不需要改动，但请确认已把 `ONTOFOUNDRY_MCP_TOKEN` 改成自己的随机值。
3. 运维脚本或监控若调用过原空间级连通性接口，改为用平台管理员会话调用 `/api/v1/system/dataagent-health`。
4. 技能已是 v0.4.1 的可不动；从更早版本升级的，按 `integrations/dataagent/迁移说明.md` 整目录替换三个技能后重启 DataAgent。
5. 回退：换回 v0.4.1 镜像和编排文件即可（无迁移）。
