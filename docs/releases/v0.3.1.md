# v0.3.1

日期：2026-11-16。基于 v0.3.0 的补丁版本，修复离线包编排中后端文件卷缺失。

## 修复

- 修复 `scripts/offline-compose.yaml`（离线安装包内的 `compose.yaml`）中 `of-backend` 未挂载 `ontofoundry-data` 卷的问题：
  - 为 `of-backend` 补充环境变量 `ONTOFOUNDRY_DATA_DIR: /var/lib/ontofoundry/files`；
  - 挂载命名卷 `ontofoundry-data:/var/lib/ontofoundry/files`；
  - 在顶层 `volumes` 声明 `ontofoundry-data`。
- 修复后，上传材料、导入原始文件与导出产物会持久化保存在 `ontofoundry-data` 卷中，不再写入容器可写层的 `/opt/ontofoundry-api/.data/files`，重建或升级 `of-backend` 容器不再丢失文件。

## 下载内容

| 附件 | 用途 |
| --- | --- |
| `ontofoundry-offline.tar.gz` | linux/amd64 平台前端、后端与 PostgreSQL 离线镜像 |
| `ontofoundry-offline.tar.gz.sha256` | 平台离线包校验和 |

DataAgent 技能自 v0.2.9 起没有变化，沿用 v0.2.9 的技能包即可。

## 升级顺序

1. 停止建模运行，备份平台数据库。
2. 如此前使用 v0.3.0（或更早离线包）上传过材料或导入过文件，升级前请先从旧 `of-backend` 容器备份 `/opt/ontofoundry-api/.data/files`（例如 `docker compose cp of-backend:/opt/ontofoundry-api/.data/files ./of-files-backup`），待用新版 `compose.yaml` 启动后再将备份目录内文件拷回新容器的 `/var/lib/ontofoundry/files/` 并重启 `of-backend`。全新部署或未上传过文件可跳过此步。
3. 使用 v0.3.1 离线包的 `compose.yaml` 与镜像升级并启动。本版**没有数据库迁移**，`.env` 配置不变。
4. 技能和两个 Agent 的配置不变，无需重装。
5. 回退：换回 v0.3.0 镜像与编排文件即可（无迁移）。
