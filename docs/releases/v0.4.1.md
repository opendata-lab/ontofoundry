# v0.4.1

日期：2026-11-18。基于 v0.4.0 之后的主干（#98）：只改建模技能，让大型结构化材料（数千到上万行的本体或语义模型 JSON、上百张关联表）能在一次运行内建完。设计见 `docs/design/2026-11-18-large-material-modeling.md`。

## 行为变化

- **平台没有变化，没有数据库迁移。** v0.4.1 技能可用于 v0.4.0 平台；平台镜像可以不升级。
- **大型 JSON 按结构读。** `read_input.py --outline` 对数组逐项列出每个元素一行（路径、原文行号、名称字段）；`--pointer` 把对象渲染成每个字段一行的可读单元，长值分段给出，可一次给多个路径。智能体不再按行号分页读原文。
- **中断后续做认中间成果。** 上一轮在 `modeling/tmp/` 整理的结果随其他成果一起保留、列出和归档；续做提示会列出这些文件和 notes 里的“待补”。
- **表清单把备份、测试、废弃、带日期后缀的表排在最后**，计划步骤会排除明显废弃的表。
- 材料是一份完整本体时，照着材料建还是按表调整由智能体判断，不另问用户。

## 升级顺序

1. 确认没有进行中的建模。
2. **整目录替换两个建模技能**（ontology-discovery、entity-extraction）和问数技能 semantic-grounding，然后重启 DataAgent。细节见 `integrations/dataagent/迁移说明.md`。
3. 平台可留在 v0.4.0；如升级到 v0.4.1 镜像，`.env` 不变，没有迁移。
4. 回退：换回 v0.4.0 技能包并重启 DataAgent。
