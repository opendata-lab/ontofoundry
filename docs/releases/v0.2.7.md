# v0.2.7

日期：2026-11-05。基于 v0.2.6 之后的主干，平台和 DataAgent 技能成套发布，与 v0.2.6 技能不兼容。

## 修复与变化

- 提交即入库：合并脚本把建模结果提交到平台，同一次检查通过即在一个事务内入库；删除只读预检接口，运行结束后平台不再下载结果文件。结果文件只含 `items`。
- 一次提交报告全部问题：条目错误一次列全；候选图校验列出每条有问题的关系、映射、规则、派生条件、数据集和指标，并提示逐个修正后整批重提。
- 每次运行最多修正 3 轮，由平台计数；通过的回执也显示已用轮数。
- 运行结束后会话状态保持“已生成 N 条提案”。
- MySQL：查询型数据集可用；enum、set、*text、year 列正确分类；数据源被拒时说明原因；绑定就绪只检查绑定实际读取的列。
- 建模技能减少无效轮次：在工作区运行初始化，打印材料与表清单，入库后直接作答；补充关联键唯一、映射字段、标题属性、规则写法的说明；未同步的表只建语义，不提数据集、映射或指标。星河零售干净环境验收中全量建模从 40 轮降到 30 轮，修正从 3 轮降到 1 轮，问数结果正确（`apps/api/evals/acceptance/results/2026-11-05-xinghe-rerun/`）。
- 问数 Agent 提示词：查询被拒时说明当前无权限，不沿用历史结果，不做无依据的数据完整性推断。
- API、前端及插件版本统一为 0.2.7。

## 升级顺序

1. 停止建模运行，备份平台数据库、文件卷、技能目录和两个 Agent 的配置。
2. 升级平台镜像。本次没有新的数据库迁移（仍为 `20261026_000001`）。
3. DataAgent 需为 main `c218dae` 或更新（沙箱网络与运行时 pip 安装）。平台安装包不包含 DataAgent 运行时。
4. 完整替换三个技能目录。建模 Agent 的 max_turns 改为 80；按 `integrations/dataagent/agents/agent_ontofoundry_qa.md` 更新问数 Agent 提示词并发布。重启 DataAgent，用新会话验收。
5. 回退时成套恢复数据库备份、平台镜像、技能和 Agent 配置，不要只降级其中一项。
