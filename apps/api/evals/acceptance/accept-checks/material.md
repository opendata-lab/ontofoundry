# 岚汀文具经营说明（虚构）

岚汀文具记录会员、订单和发货单三类业务。
会员以会员编号唯一标识，会员等级只有“普通”和“金卡”两种。
订单以订单号唯一标识，每张订单只属于一位会员；订单记录件数（整数）、实付金额、下单时间（精确到分钟）、订单状态和下单渠道（门店或线上）。
发货单以发货单号唯一标识，对应一张订单；发货数量必须填写。
金额超过 5000 元的订单，下单会员必须是金卡会员。
指标“发货件数”：发货单表 shipments 的 ship_qty 列求和。
指标“已支付金额”：订单状态为“已支付”的订单实付金额求和。
