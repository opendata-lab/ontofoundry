# 青禾生鲜超市经营管理说明

青禾生鲜超市是一家虚构的区域连锁超市，按大区管理门店，商品从供应商采购进仓库，再调拨到门店销售；线上订单可配送到家。以下是业务部门对经营口径的说明。

## 组织与门店

- 门店归属一个大区，每个大区有一名大区经理。门店分标准店、社区店、旗舰店三类，有营业、装修、闭店三种状态；闭店后不再统计到“在营门店”。
- 每家门店有一名店长（员工）。员工属于门店，总部员工不属于任何门店。
- 仓库分常温仓和冷链仓，生鲜商品只能存放在冷链仓。

## 商品

- 商品以商品编码（SKU）唯一识别，属于一个二级品类，二级品类归属一级品类。商品有品牌，部分品牌是自有品牌。
- 商品有零售价、会员价和进价。会员价只对会员生效。门店可以单独调价，调价记录保留原价、新价和生效时间。
- 生鲜商品保质期短，剩余保质期不足三分之一的称为“临期商品”，需要打折处理。
- 每个商品有一个主供应商。

## 采购与库存

- 采购员向供应商下采购单，货到仓库后生成入库单；入库时可以拒收，拒收数量不计入库存。
- 仓库通过调拨单把商品发往门店，到店后门店库存增加。
- 每天日终对每个仓库和门店的每个商品做库存快照，记录数量和成本。
- 门店定期盘点，实盘数量少于账面数量的部分算“盘亏”，盘亏成本计入损耗。

## 销售与会员

- 顾客在门店、小程序或外卖渠道下单。会员下单记会员编号，散客为空。
- 订单状态有待支付、已完成、已取消，只有已完成的订单计入销售。一单可以用多种方式支付。
- 会员分普通、银卡、金卡、黑卡四个等级，按积分升级。会员可以领取优惠券，下单时核销。
- 促销活动分满减、折扣、第二件半价，活动关联参与的商品。订单明细记录参与了哪个活动。
- 退款分整单退和部分退，审核通过后才算退款完成。

## 配送

- 选择配送到家的订单会生成配送单，由合作配送商的骑手送达。配送单有承诺送达时间。

## 经营指标口径

- 销售额：已完成订单的实付金额合计，减去已完成退款的退款金额。
- 订单数：已完成订单的数量。
- 客单价：销售额除以订单数。
- 毛利：销售额减去已售商品的进价成本。毛利率 = 毛利 / 销售额。
- 会员销售占比：会员订单的销售额占全部销售额的比例。
- 会员复购率：统计期内下单两次及以上的会员数占下单会员数的比例。
- 动销率：统计期内有销售的在售商品数占在售商品总数的比例。
- 库存周转天数：平均库存成本除以日均销售成本。
- 盘亏损耗率：盘亏成本占同期销售成本的比例。
- 准时送达率：在承诺时间前送达的配送单占已送达配送单的比例。
- 优惠券核销率：已使用的发放张数占发放总张数的比例。
