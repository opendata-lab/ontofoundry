真实 DeepSeek 建模与问数验收的完整记录，用于回顾与对外讲解效果。每次验收一个目录 `results/<日期-场景>/`：材料、各步骤的完整对话（`conversation.json`）、运行状态、截图，以及 `NOTES.md`（过程、结论、修正、花费、标准答案）。场景与数据均为虚构；本机路径已替换为 `~`，存档前检查不含令牌与密码。
