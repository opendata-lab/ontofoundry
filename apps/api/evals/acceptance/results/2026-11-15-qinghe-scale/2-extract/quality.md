# 对照材料与固定参照的静态核对

## 已交付

30 个实体类型覆盖业务主单、明细和维度。技术日志、迁移备份、日期维表均未建实体或数据集。促销商品关联表作为多对多关系来源。全部 44 条关系覆盖 README 指明的业务关系。实体、属性、关系的名称和定义可在 batch.json 核查。

计划按材料 11 条指标口径拆为 12 个指标元素（毛利、毛利率分开），批准后交付其中 10 个，另有 9 个支撑指标，共 19 个。缺会员复购率、动销率，Agent 在最终回复中明确列出。

规则实际 25 条，其中 24 条为枚举取值约束，1 条是自行推导的“实付金额构成”。该推导声明需要人工确认，用户按照本任务全接受操作发布，并未追加业务口径确认。

## 缺失与偏差

- 指定的六条业务规则没有作为规则元素提出。仅已完成订单计销售和已退款计退款通过净销售数据集 SQL 的状态过滤表达。拒收不计库存、生鲜只能冷链存储、临期不足三分之一、闭店不计在营缺少可执行或明确的规则定义，临期仅在属性说明中提及。
- 库存快照到仓库/门店的多态关系没有提出，Agent 在回复中说明暂缓处理。该项超过 README 列出的关系清单，来自材料库存地点语义。
- 增加 3 个 SQL 查询数据集和 9 个支撑指标。按日库存/成本 SQL 使用有业务记录日期的并集，描述“无销售日期按 0”仅覆盖该并集中的日期，统计期完全无记录的日期不产生行。该差异依据 SQL 静态核对，未运行指标查询。
- 实付金额推导规则来自字段名与注释，包含“空值按 0”的说明，但表达式未体现空值处理。材料没有给出该公式或额外调整项的完整口径。

本核对依据归档提案、片段和材料完成。指标查询正确性与数据值没有执行验收。
