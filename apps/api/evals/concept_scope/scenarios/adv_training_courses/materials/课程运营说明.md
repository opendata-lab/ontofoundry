# 启明职业培训课程运营说明（虚构）

## 机构历程

启明职业培训创办于 2012 年，最初只开设会计课程，2018 年迁入青岚软件园，2023 年获评“青岚市职业技能培训优秀机构”。本节仅作背景介绍，不属于课程运营的内容。

## 课程与开班

课程是机构对外提供的培训项目，记录课程编号、课程名称、课时数和课程级别；课程级别是课程上的一个字段，取值为初级、中级、高级。例如 KC-101《Python 数据分析》、KC-205《财务报表实务》。

同一门课程可以多次开班。每次开班是一个独立的业务对象，记录开班编号、开课日期、结课日期、上课地点和计划招生人数，例如开班编号 KB-26S01 的“2026 春季 Python 数据分析 1 班”。每次开班属于一门课程。

## 学员与报名

学员报名时选择某次开班。材料和系统中“学员”和“学生”指同一类人，记录学员编号、姓名、手机号和身份证号后四位，例如学员编号 S2601 的陈思远。

每条报名记录对应一位学员和一次开班，记录报名日期、缴费金额和报名状态；报名状态是报名记录上的一个字段，取值为已报名、已缴费、已退费。

## 授课

每次开班安排若干位讲师授课。讲师记录讲师编号、姓名和擅长方向，例如讲师编号 T07 的方立。同一位讲师在一次开班中担任“主讲”或“助教”；主讲和助教是讲师在该次开班中的角色，不是另一类人。每条授课安排记录一位讲师在一次开班中的角色和授课课时数。

## 管理口径

开班满员率 = 实际报名人数 ÷ 计划招生人数；退费率 = 已退费的报名记录数 ÷ 报名记录总数。
