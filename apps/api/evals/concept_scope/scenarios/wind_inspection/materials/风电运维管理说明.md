# 东岭风电运维管理说明（虚构）

本说明涉及两个风电场：东岭一号风电场、西坡风电场。每个风电场有多台风机，每台风机属于一个风电场，记录风机编号、型号、额定功率和投运日期，例如东岭一号风电场的 F-07、F-12，西坡风电场的 W-03。

运维人员按班组管理。每个班组记录班组名称和负责的风电场，例如“东岭巡检一班”“西坡巡检班”。每名运维人员属于一个班组，记录工号、姓名和资质等级，例如工号 E1021 的赵凯、工号 E1033 的林溪。

巡检任务按计划执行：每个巡检任务针对一台风机，记录计划日期、实际完成日期和执行的运维人员。巡检中发现的问题登记为缺陷，每条缺陷属于一个巡检任务，记录缺陷等级和描述；缺陷等级是缺陷上的一个字段，取值为一般、严重、紧急。

严重和紧急缺陷必须开维修工单。每张维修工单对应一条缺陷，记录派单时间、完工时间和维修费用。

管理口径：缺陷闭环率 = 已完工的维修工单数 ÷ 应开维修工单的缺陷数；月度巡检完成率 = 当月按期完成的巡检任务数 ÷ 当月计划巡检任务数。
