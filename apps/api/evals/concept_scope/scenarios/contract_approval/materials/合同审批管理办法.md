# 青禾科技合同审批管理办法（虚构）

合同是本办法的管理对象。每份合同记录合同编号、合同名称、合同金额、签订日期和合同类型；合同类型是合同上的一个字段，取值为采购、销售、服务。例如 HT-2026-018《服务器采购合同》、HT-2026-031《年度运维服务合同》。

每份合同有一个签约相对方。相对方是与我方签约的外部单位，记录统一社会信用代码、单位名称和联系人，例如“北辰数据有限公司”“南溪设备厂”。

每份合同由一个经办部门发起。部门记录部门编号和部门名称，例如采购部、法务部。

合同发起后进入审批，每份合同依次产生若干条审批记录。每条审批记录对应一份合同，记录审批人、审批环节、审批结果和审批时间；审批环节和审批结果都是审批记录上的字段，审批环节取值为部门负责人、法务、财务、总经理，审批结果取值为同意、驳回。审批人是公司员工，员工记录工号、姓名和所属部门，例如工号 Q207 的周宁。

合同金额超过 50 万元的必须经总经理审批。

已生效的合同按付款计划付款。每份合同可以有多期付款计划，每期付款计划记录期次、计划付款日期和计划金额。

管理口径：合同平均审批时长 = 每份合同最后一条审批记录的时间与发起时间之差的平均值。
