# 青柠社区诊所预约与处方说明（虚构）

诊所设有科室，如全科、儿科、口腔科。每位医生隶属一个科室，记录医生编号、姓名和职称；职称是医生上的一个字段，取值为主治医师、副主任医师。例如全科的许医生（D01）、儿科的唐医生（D05）。

患者通过线上预约医生：一次预约对应一位患者和一位医生，记录预约日期、时段和预约状态；预约状态是预约上的一个字段，取值为已预约、已就诊、已取消、爽约。患者记录患者编号、姓名、性别和出生日期。

就诊后医生开具处方，一张处方对应一次预约。处方由若干处方明细组成，每条处方明细记录药品和数量，以处方号加行号标识。药品记录药品编码、名称、单价和类别，例如阿莫西林胶囊、布洛芬混悬液。

daily_visit_stats 是按科室和日期汇总的每日就诊人次统计表，由夜间任务从预约表计算生成，不是独立的业务对象。

管理口径：爽约率 = 预约状态为爽约的预约数 ÷ 预约总数；人均处方金额 = 处方总金额 ÷ 开具过处方的患者数。
