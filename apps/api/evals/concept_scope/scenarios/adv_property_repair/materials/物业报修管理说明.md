# 青檀物业报修管理说明（虚构）

## 公司简介

青檀物业成立于 2009 年，总部位于青岚市，曾获“青岚市物业服务示范单位”称号，现有员工三百余人。本节仅作背景介绍，不属于报修管理的内容。

## 报修

住户发现房屋设施损坏时提交报修单。系统里也把报修单称为“工单”，两者指同一个东西。每张报修单记录报修编号、报修时间、问题描述和紧急程度；紧急程度是报修单上的一个字段，取值为普通、加急、特急。例如报修编号 BX-0315 的“厨房水管漏水”。

每张报修单由一位住户提交。住户记录住户编号、姓名、联系电话和所住房屋。房屋记录房号和建筑面积，每套房屋属于一栋楼栋，例如 3 栋 1502 室。楼栋记录楼栋编号和楼层数，例如 3 栋、7 栋。

## 派单与维修

每张报修单派给一位维修工处理。维修工记录工号、姓名和工种；工种是维修工上的一个字段，取值为水电工、木工、空调工。例如工号 W012 的韩师傅。

维修完成后，提交报修单的住户对这次维修打分，此时住户也被称为“评价人”。评价人就是住户本人，不是另一类人。

维修工按排班上岗：每条排班记录一位维修工在某一天的某个班次以及值守的楼栋；班次是排班上的一个字段，取值为早班、晚班。

维修工负责哪些楼栋记录在 worker_buildings 表中。这张表只有维修工工号和楼栋编号两列，只用来表示维修工与楼栋之间的负责关系。

## 管理口径

报修及时完成率 = 在承诺时限内完成的报修单数 ÷ 报修单总数；住户满意度 = 住户评分的平均值。
