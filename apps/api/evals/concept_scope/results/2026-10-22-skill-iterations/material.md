# 星云平台组件台账（虚构）

星云平台由多套中间件组件支撑，分布在开发、测试、生产三套环境中。

## 组件
- Apache HTTP Server：对外网关，版本 2.4，由运维一组负责。
- Nginx：静态资源反向代理，版本 1.24，由运维一组负责。
- Redis：缓存，版本 7.2，部署在测试环境和生产环境，由数据平台组负责。
- MySQL：业务库，版本 8.0，生产环境主从部署，由数据平台组负责。
- Kafka：消息队列，版本 3.6，由数据平台组负责。

## 环境
- 开发环境（dev）：供研发自测，变更无需审批。
- 测试环境（test）：集成测试使用。
- 生产环境（prod）：对外服务，变更需审批。

## 负责团队
- 运维一组：负责网关与反向代理类组件。
- 数据平台组：负责存储与消息类组件。

## 部署
同一个组件可以部署到多个环境。每次部署记录部署的组件、环境、版本、主机名和部署时间；生产环境的部署需要记录审批人。
