# 城市公交调度业务说明

本文的单位、人物、地点与编码均为虚构。澄栖公共交通公司早年用蓝色纸签传递消息，后来将纸签装订成册，周年时举办过纸船展览，还把“慢行看潮”印在纪念册封底。这段沿革只作背景，公司、纸签、展览、纪念册和口号均不属于本次管理范围。

公交线路的字段为线路编号、线路名称、核定里程；岚湾环行线的线路编号为LW-47。每条线路按顺序经过多个公交站点，同一站点可被多条线路经过。公交站点的字段为站点编号、站点名称、经度、纬度，苇灯口站和砚沙桥站是两个具体站点；途经顺序属于线路与站点的关系信息。

公交车辆的字段为车辆编号、核载人数、车辆状态，CX-731是一辆具体车辆的编号。车辆状态只取“候场”“执行”“封存”，三者是状态值，不单独管理。车场的字段为车场编号、车场名称、停车容量；蒲汀车场是一处具体车场，每辆车归属一个车场。

运营班次表示某线路某日的一次计划发车，字段为班次编号、运营日期、计划发车时刻、实际发车时刻。班次BC-8261属于岚湾环行线，使用车辆CX-731，从蒲汀车场出场。线路是可反复使用的路线定义，班次是有独立编号的单次安排，二者分别管理。

员工的字段为员工编号、员工姓名、联系电话，叶澄禾与陆闻舟是两位员工。调度指令指定某班次使用哪辆车，字段为指令编号、创建时刻、处置档位，每份指令关联一个班次、一辆车和两位经办员工。处置档位只取“青苗”“银帆”“赤隼”，紧急程度依次递增；三者仅是枚举标签，不对应实体。

交接时，调度指令又被称为派车单，两种叫法指同一业务对象，编号相同。派车单PD-518由叶澄禾担任发起人、陆闻舟担任复核人；派车单PD-519则由陆闻舟发起、叶澄禾复核。发起人和复核人均为员工的办理角色，不另建人员类别。

管理口径计算两个指标：按时发车率＝统计日实际发车时刻与计划发车时刻相差不超过三分钟的班次数÷统计日应发班次数×100%；车辆出勤率＝统计日承担过至少一个已发班次的车辆数÷统计日归属各车场的车辆总数×100%。它们由记录汇总计算，不作为实体。
